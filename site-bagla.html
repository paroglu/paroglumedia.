Mevcut siteye
portföy bağlantısı ekle.

Bu araç yayındaki gerçek index.html dosyanı okur ve yalnızca kapanış </body> öncesine bir script bağlantısı ekleyerek yeni bir dosya indirir. Diğer HTML, CSS, video, animasyon veya logolara dokunmaz. Hiçbir şeyi otomatik olarak GitHub'a yüklemez.

1
Önce portfoy.html ve pm-portfolio-bridge.js dosyalarını GitHub deposunun ana dizinine yükle.
2
İki dosya yayına alındıktan sonra aşağıdaki düğmeye bas. Araç, sitedeki mevcut index.html dosyasını temel alarak yeni index.html dosyasını indirecek.
3
İndirilen dosyayı GitHub'a index.html adıyla yükle ve Commit changes yap. Eski dosya GitHub geçmişinde kalır.
Hazır. Ana siteye hiçbir değişiklik yapılmadı.

Not: Tarayıcın dosyayı index(1).html gibi adlandırırsa GitHub'a yüklemeden önce adını tam olarak index.html olarak düzelt.
